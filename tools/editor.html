자료 선택

사용 방법 확인
  1. 메뉴 선택 후 ‘새 게시물’ 또는 수정할 게시물 선택
  2. 내용 입력 후 ‘목록에 반영’ 선택
  3. ‘JSON 다운로드’를 눌러 파일 내려받기
  4. GitHub의 data 폴더에 같은 이름으로 올려 기존 파일 교체
  • JSON: 게시물 목록을 담는 파일
  • 사이트 반영: 내려받은 JSON을 GitHub에 업로드한 뒤 적용
  • 창을 닫기 전: 작업 내용이 사라지지 않도록 JSON 다운로드
  • PDF·이미지: 경로 입력과 별도로 실제 파일도 GitHub에 업로드

게시물 목록 불러오는 중

추가 첨부자료

  • 자료 이름: 화면에 보일 이름 입력
  • 파일 경로: GitHub에 올려 둔 파일의 위치 입력
  • 자료가 여러 개라면 ‘첨부자료 추가’ 선택
  • 필요 없는 자료는 해당 줄의 ‘삭제’ 선택
  • 다운로드 파일: 지금 선택한 메뉴의 전체 게시물 포함
  • 사이트 반영: GitHub의 data 폴더에 같은 이름으로 업로드
